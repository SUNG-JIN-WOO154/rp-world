# 🎮 RP WORLD - Jeu RPG Futuriste Ultra-Long

## 📋 Bienvenue dans l'univers de RP World

TP World est un jeu RPG persistant et immersif où tu navigues un monde post-apocalyptique rempli de choix moraux, de récolte de ressources, d'aventures épiques et de conséquences permanentes.

### 🌍 Caractéristiques principales

✅ **Histoire ultra-longue** : 50+ scénarios narratifs avec plusieurs fins  
✅ **Système de progression** : Niveaux, expérience, réputation, or  
✅ **Choix impactants** : Facile, Risqué, Caché, Loyal, Traître  
✅ **Inventaire dynamique** : Collecte, équipement, artisanat  
✅ **Sauvegarde locale** : Ton progrès persiste dans ton navigateur  
✅ **Interface futuriste** : Design néon cyberpunk ultra-moderne  
✅ **Zones explorables** : Ruines, forêts, cités flottantes, abysses  
✅ **Nombreuses factions** : Camp de survivants, Garde du Ciel, Réseau ancien  

---

## 🚀 Débuter le jeu

1. Ouvre `index.html` dans un navigateur web moderne
2. Clique sur "NOUVEAU JEU"
3. Prends tes décisions sagement
4. Clique sur "SAUVEGARDER" pour persister ta progression

## 📊 Système de jeu

### Ressources principales
- **PV (Santé)** : Diminue lors des combats, se régénère au repos
- **Énergie** : Dépensée lors des actions, se régénère avec le repos
- **Or** : Monnaie pour acheter et commercer
- **Réputation** : Affecte les dialogues et les alliances possibles
- **Expérience** : Gain de niveaux qui augmentent tes capacités
- **Inventaire** : Collecte d'objets pour accomplir des quêtes

### Arcs narratifs majeurs

**Arc 1 - L'Éveil** (30-45 minutes)  
Découvre le monde et choisis ton premier chemin.

**Arc 2 - Exploration** (1-2 heures)  
Explore les zones, fais des alliances, récolte des ressources.

**Arc 3 - Quête des Artefacts** (1-2 heures)  
Recherche les trois artefacts cachés pour accéder au cœur du réseau.

**Arc 4 - Confrontation finale** (30-60 minutes)  
Affrontement avec le réseau ancien et choix du futur du monde.

## 🌐 Comment déployer le jeu

### Option 1: GitHub Pages (GRATUIT, FACILE) ⭐
1. Va à ton repo sur GitHub
2. Paramètres > Pages
3. Choisis "main" comme branche
4. Ton jeu est en ligne à `https://USERNAME.github.io/rp-world`

### Option 2: Netlify (GRATUIT, RAPIDE)
1. Va sur https://app.netlify.com/drop
2. Glisse-dépose ton dossier du jeu
3. Ton jeu est en ligne en quelques secondes

### Option 3: Vercel (GRATUIT, PERFORMANT)
1. Connecte ton repo à https://vercel.com
2. Configure avec les paramètres par défaut
3. Ton jeu est en ligne automatiquement

### Option 4: Heroku (GRATUIT avec compte)
1. Crée une app Heroku
2. Ajoute un `Procfile`: `web: python -m http.server $PORT`
3. Git push vers Heroku

### Option 5: Fichier statique (ULTRA-SIMPLE)
1. Glisse-dépose ton dossier sur un navigateur
2. Ouvre `index.html`
3. Joue hors ligne, aucune configuration nécessaire

### Option 6: Serveur personnel (VPS)
1. SSH vers ton serveur
2. `git clone https://github.com/USERNAME/rp-world`
3. `python -m http.server 8000` ou `npx http-server`
4. Accède via `http://IP:PORT`
