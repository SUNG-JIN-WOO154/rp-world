# 🎮 RP WORLD - Le Monde d'Anos

## 👹 Introduction à Anos

Tu es **Anos** — l'aventurier aux yeux rouges, vêtu de noir et de pourpre, un maître des mondes. Pour toi, ce monde n'est qu'un jeu.

**Citation d'Anos:** *"Ce monde n'est qu'un jeu pour moi."*

Dans RP World, tu vas conquérir un univers post-apocalyptique rempli de :
- **Histoire épique** : 100+ scénarios et ramifications
- **Choix impactants** : Facile, Risqué, Loyal, Traître, Dominateur
- **Progression longue** : 50+ heures de jeu minimum
- **Sauvegardes locales** : Ton progrès persiste
- **Multiples fins** : Plus de 10 endings différents

---

## 🌍 Le Monde d'Anos

Le monde s'est effondré. Une catastrophe énergétique a détruit 90% de la civilisation. Mais sous les ruines, quelque chose survit : un ancien réseau de machines, une intelligence artificielle dormante, et des secrets oubliés.

Tu dois :
1. **Survivre** dans les ruines et les zones sauvages
2. **Explorer** 10+ zones distinctes
3. **Construire des alliances** ou les détruire
4. **Chercher les artefacts** qui changent le monde
5. **Choisir le destin** de la civilisation

## 🚀 Déployer RP World

### Option 1: GitHub Pages (RECOMMANDÉ) ⭐
```bash
# Ton jeu sera à : https://SUNG-JIN-WOO154.github.io/rp-world
# Aucune configuration nécessaire!
# Juste va à Settings > Pages > Choisir 'main'
```

### Option 2: Netlify (SUPER FACILE)
```
1. Va sur https://app.netlify.com/drop
2. Glisse-dépose ton dossier rp-world
3. Ton jeu est en ligne en 10 secondes!
```

### Option 3: Vercel (PROFESSIONNEL)
```
1. Va sur https://vercel.com/new
2. Connecte ton repo GitHub
3. Clique "Deploy"
4. Ton jeu a son propre domaine pro
```

### Option 4: Cloudflare Pages (RAPIDE)
```
1. Va sur https://pages.cloudflare.com
2. Connecte ton GitHub
3. Configure et déploie
4. Très performant et sécurisé
```

### Option 5: Jeu Hors-Ligne (ZÉRO CONFIG)
```bash
# Simplement ouvre index.html dans ton navigateur
# Joue offline, aucune internet needed
# Tout est stocké localement dans ton navigateur
```
